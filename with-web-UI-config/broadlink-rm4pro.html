RF-Code einlernen

1. Taste lange gedrückt halten, bis eine Frequenz erkannt wird.
2. Taste erneut kurz drücken, um den RF-Code aufzuzeichnen.
3. Der Code wird gespeichert und die Dynamic Action registriert.
